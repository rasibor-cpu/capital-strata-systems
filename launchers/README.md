# CSS Launcher

Double-click `CSS Dashboard.cmd` to start Capital Strata Systems with the graphical sign-on screen.

Double-click `CSS Mobile Server.cmd` to start the phone-access web app. Open the printed `http://<pc-ip>:8090` address from a phone on the same network.

To create a Desktop shortcut, run:

```powershell
powershell -ExecutionPolicy Bypass -File .\launchers\install_css_desktop_icon.ps1
```
