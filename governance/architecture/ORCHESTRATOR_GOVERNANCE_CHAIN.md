# CSS Orchestrator Governance Chain

## Purpose
Defines the approved orchestration decision hierarchy.

## Chain
1. Scanner and signal intake
2. Opportunity normalization
3. Intelligence scoring
4. Regime validation
5. Risk and governance gates
6. Allocation governor
7. Unified trade gate
8. Execution permission checks
9. Broker routing
10. Audit logging
11. PnL and runtime state update

## Fail-Closed Principle
When authority, mode, balance, broker status, or governance state is ambiguous, CSS must fail closed.

## Rogue Path Rule
No direct or hidden execution route may bypass the orchestrator, governance gate, or broker authority.
