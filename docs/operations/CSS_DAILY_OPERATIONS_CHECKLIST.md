CSS Daily Operations Checklist

Purpose

This checklist defines the daily operational procedures for Capital Strata Systems (CSS).

The objective is to ensure consistent operational readiness, risk control validation, broker verification, and monitoring review before and after trading activities.

---

Platform Validation

Verify:

- Application files present
- Configuration files present
- No known unresolved critical incidents
- Latest approved release deployed

During Operations

Monitor:

- Broker status
- Engine status
- Open positions
- PnL movement
- Drawdown levels
- Alert activity
- Security events

Review Frequency:

- Minimum every 30 minutes
