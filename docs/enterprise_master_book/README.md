## Purpose

This index is the entry point for the CSS Enterprise Master Book framework created under **CEP-001**.

The Master Book is the authoritative source for:

* product positioning,
* commercial claims,
* website content,
* sales and investor materials,
* pilot documentation,
* customer-facing product descriptions,
* certification summaries for external communication.

## Authority

Commercial materials must follow this hierarchy:

1. Canonical release status — [../release/CSS_CANONICAL_RELEASE_STATUS.md](../release/CSS_CANONICAL_RELEASE_STATUS.md)
2. Approved repository evidence
3. Enterprise Master Book
4. Derived commercial materials

No derived material may contradict higher authority.
