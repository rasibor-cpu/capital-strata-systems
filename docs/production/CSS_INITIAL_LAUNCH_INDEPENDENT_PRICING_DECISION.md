# CSS Initial Launch Independent-Trade Pricing Decision

Status: INTERNAL COMMERCIAL DECISION — CLOSED FOR INITIAL LAUNCH
Effective scope: Initial production launch only

## Decision

For the initial production launch, CSS will charge:

- CSS-attributable accepted advice:
  performance compensation only on qualifying fresh economic gain after any
  prior CSS-attributable loss has been fully recovered.

- CUSTOMER_DIRECTED or materially modified independent activity:
  no separate CSS platform/service charge at launch.

- EXTERNAL trades:
  excluded from CSS economics.

## Rationale

This launch posture:

- keeps the customer proposition simple;
- avoids making the independent/customer-directed path look like a second
  performance-fee arrangement;
- preserves the clean provenance boundary already implemented in CSS;
- reduces legal/contract complexity during initial production approval;
- keeps the existing independent-charge engine available but disabled unless a
  later policy is explicitly approved.

## Future change rule

A future independent/customer-directed platform fee may be introduced only
through:

1. a new explicit policy ID/version;
2. a clearly defined non-performance charging basis;
3. commercial-owner approval;
4. counsel/regulatory review for the target jurisdiction;
5. versioned customer agreement/pricing disclosure;
6. required customer notice/re-consent;
7. updated UAT/reconciliation evidence.

The existing POSITIVE_REALIZED_PERCENTAGE model remains shadow/test capable but
is not the initial production charging policy.

## Contract instruction

The initial production customer agreement should state that no CSS
platform/service fee is charged on CUSTOMER_DIRECTED or CSS_MODIFIED independent
activity unless the customer later accepts a separately versioned pricing
change.

Counsel must still approve the agreement wording, but no separate open internal
pricing decision remains for the initial launch.
