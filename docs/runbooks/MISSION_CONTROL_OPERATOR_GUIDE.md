# Mission Control Operator Guide

## Purpose

Mission Control gives operators a consolidated view of runtime, broker,
portfolio, risk, decision, governance, and certification evidence.

## Operator Flow

1. Open Mission Control from the existing CSS dashboard host.
2. Confirm the top status bar shows read-only safety posture.
3. Review Executive Overview for runtime, broker, risk, and certification
   status.
4. Use Runtime Operations for heartbeat, timeline, source, and system metrics.
5. Use Broker Management for readiness and registry evidence.
6. Use Certification and Readiness for final certification status.

## Offline Handling

If the runtime is unavailable or stale, Mission Control displays a fail-closed
banner and unavailable evidence. Operators should treat this as no current
runtime evidence.

## Restrictions

Mission Control is display-only. Operators cannot change roles, configuration,
broker state, runtime state, limits, credentials, or trade authority here.
