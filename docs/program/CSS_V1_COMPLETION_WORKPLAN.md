# CSS v1.0 Completion Program

Status: ACTIVE
Start: 2026-09-13
Target: shortest safe path to a website + phone release candidate ready for controlled live testing.

## Governing principles
- Work in parallel across broker/QRO, commercialization, product/UX, simulator/intelligence, resilience/security, operations/legal readiness, and release engineering.
- No live execution, broker fund movement, or fee collection is enabled by this program.
- Fail closed on stale/unknown broker state, missing provenance, missing authorization, and incomplete evidence.
- Every increment requires deterministic tests, explicit acceptance criteria, and auditable evidence.
- Phone and website must use the same canonical domain/state projections; no duplicated business logic.

## Program lanes
1. Session-10 controlled-live-read readiness and broker-provider abstraction.
2. Commercialization truth: provenance -> attributable performance -> hurdle -> fee entitlement -> presentation.
3. Website + phone Mission Control and customer experience parity.
4. Simulator Academy, adaptive coaching, what-if/stress laboratory, explainability, forecasting, analytics, benchmarking, drift.
5. Security, failure injection, backup/restore, rollback, endurance.
6. Regulatory/commercial operating readiness, privacy, incident/support model.
7. Release engineering, evidence automation, RC freeze, controlled-live-test certification.

## Completion gates
G1 Session-10 disposition
G2 Commercialization completion
G3 Product/mobile parity
G4 Intelligence + desired enhancements
G5 Production hardening
G6 Legal/operations readiness
G7 RC/endurance/final certification

## User-input policy
Default to autonomous execution. Request user input only for:
- external credentials/authorization that cannot be delegated;
- legal/regulatory decisions requiring the owner;
- explicit live-execution or money-movement authorization;
- irreversible product/business-policy decisions with material consequences.

Everything else should be researched, implemented, tested, reviewed and documented remotely.
