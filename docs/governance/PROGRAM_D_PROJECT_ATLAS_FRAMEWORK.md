# CSS Enterprise Program D — Project Atlas Framework

## Purpose

Project Atlas is the read-only engineering knowledge index for CSS operational,
security, governance, certification, and architecture artifacts.

It is an index and navigation framework, not an execution system.

## Canonical entry fields

- entry_id
- title
- category
- repository path
- lifecycle status

## Initial categories

- OPERATIONS
- SECURITY
- GOVERNANCE
- CERTIFICATION
- ARCHITECTURE
- RESEARCH

## Safety

Project Atlas contains references only. It cannot:

- alter runtime state;
- edit broker configuration;
- enable execution;
- move money;
- expose credentials.

Future Atlas work may add search, dependency links, and ownership metadata while
remaining read-only.
